클라우드 동기화

연결하면 휴대폰과 PC에서 같은 기록을 함께 씁니다. 가계부 목록도 함께 맞춰집니다.

  1. supabase.com에 가입하고 새 프로젝트를 만듭니다. (무료, 카드 불필요)
  2. 왼쪽 메뉴 SQL Editor에서 아래 내용을 붙여넣고 실행합니다.
create table if not exists ledger_docs ( id text primary key, doc jsonb not null, updated_at bigint not null default 0 ); alter table ledger_docs enable row level security; create policy "app access" on ledger_docs for all to anon using (true) with check (true);
  1. Settings → API(또는 API Keys)에서 Project URL과 publishable 키(없으면 anon 키)를 복사해 아래에 넣습니다.
  2. 공간 이름은 아무 값이나 정하시되, 다른 기기에서도 똑같이 입력해야 같은 가계부에 연결됩니다. 가계부가 여러 개여도 공간 이름은 하나면 됩니다.

휴대폰 알림·문자를 자동으로 받아오려면 아래도 함께 설정하세요.

  1. SQL Editor에서 아래 내용을 추가로 실행합니다.
create table if not exists ledger_inbox ( id bigserial primary key, space text not null, body text not null, at bigint not null default 0 ); alter table ledger_inbox enable row level security; create policy "app inbox" on ledger_inbox for all to anon using (true) with check (true); -- 알림 원문을 그대로 받는 함수 -- '공간 이름' 자리에 위에서 정한 공간 이름을 넣으세요 create or replace function add_inbox(text) returns void language sql as $$ insert into ledger_inbox(space, body, at) values ('공간 이름', $1, (extract(epoch from now())*1000)::bigint); $$; grant execute on function add_inbox(text) to anon;
  1. 휴대폰에 MacroDroid를 설치합니다.
  2. 매크로를 3개 만듭니다. 트리거만 다르고 동작은 셋 다 똑같습니다.

비용 안내 · 무료로 쓰려면 광고를 보고 사용 기간을 3일씩 연장해야 합니다. 깜빡하면 알림 수집이 조용히 멈춰서 며칠 치 결제가 통째로 빠질 수 있으니, 계속 쓰실 생각이면 Pro 일회성 결제를 권합니다. 구독이 아니라 한 번만 내면 됩니다.

① 매크로마다 다른 부분 — 트리거
기기 이벤트 → 알림 수신 → 앱을 고르고 포함할 텍스트를 채웁니다. (‘정규식’ 옵션 켜기)

매크로 1 앱: 메시지 포함할 텍스트: 신한[^\n]{0,4}\(\d{4}\)|\[신한체크(승인|취소)\]|우리카드\(\d{4}\) 매크로 2 앱: 토스 + 토스뱅크 ← 둘 다 고릅니다 포함할 텍스트: 카드 \| 매크로 3 앱: 카카오톡 포함할 텍스트: 토스뱅크

‘승인’·‘취소’처럼 흔한 단어만 넣으면 광고·예약취소 문자까지 서버로 올라갑니다. 괄호와 숫자 네 자리를 함께 요구하면 카드사 광고 문자가 걸러집니다.

토스는 ‘원 결제’로 잡으면 안 걸립니다. 금액은 알림 제목에만 있고 포함할 텍스트는 보통 본문만 봅니다. 본문은 생활비 카드 | 세븐일레븐 신림본점 꼴이라 카드 \|로 잡습니다. 그래도 안 걸리면 잔액으로 바꿔 보세요(입금·이체 알림까지 올라오지만 지우면 됩니다). 알림에 뜨는 앱 이름이 토스뱅크일 때가 있어 앱은 둘 다 골라 두는 편이 안전합니다.

[꼭 확인할 것] 알림 소리 조건 없음 ← '소리 없음'이면 아무것도 안 걸립니다 RegEx 사용 켜기 연속 발동 방지 끄기 ← 같은 내용이 반복될 때 두 번째부터 무시됩니다 매직 텍스트 Body 내용에 직접 타이핑하지 말고 입력칸 옆 [...] 버튼으로 '알림 텍스트'를 고르세요 (기기·설정에 따라 변수 이름이 다릅니다)

알림 소리가 가장 자주 걸리는 함정입니다. 기본값이 ‘소리 없음’인 경우가 있는데, 그러면 소리가 나는 실제 결제 알림이 전부 걸러집니다. 잘 안 될 때는 ☰ 메뉴 → 문제 해결 → 시스템 로그에서 걸러진 이유를 확인하세요.

② 매크로 3개에 똑같이 넣는 부분 — 동작
네트워크 → HTTP 요청

[설정] 탭 요청 종류 POST URL <Project URL>/rest/v1/rpc/add_inbox [헤더 파라미터] 탭 ※ 두 개만 넣습니다 apikey <API 키> Authorization Bearer <API 키> [Body 내용] 탭 컨텐츠 타입 text/plain Body 내용 [...] 버튼 → '알림 제목' 선택 줄을 바꾸고 [...] 버튼 → '알림 텍스트' 선택 (직접 입력하면 변수 이름이 달라 동작하지 않습니다)

제목과 텍스트를 두 줄로 함께 보내세요. 토스 앱 알림은 금액이 제목에 있고 카드·가맹점이 텍스트에 있어서, 텍스트만 보내면 금액이 없어 읽지 못합니다. 문자 매크로도 같은 방식이면 그대로 두면 됩니다.

형식을 몰라 읽지 못한 알림은 버리지 않고 문자로 기록 추가 카드 아래 ‘읽지 못한 알림’에 원문 그대로 남습니다. 거기서 직접 추가를 누르면 대기 목록으로 넘어가고, 모두 복사로 원문을 꺼내 볼 수도 있습니다.
Content-Type은 Body 탭에서 text/plain을 고르면 자동으로 붙으니 헤더에 따로 넣지 마세요. 알림 원문을 그대로 보내는 방식이라 줄바꿈·따옴표가 있어도 깨지지 않습니다. 함수를 만든 직후에는 1분쯤 기다렸다 시험해 보세요.

  1. 설정 → 배터리에서 MacroDroid를 최적화 제외로 두면 절전 중에도 놓치지 않습니다.

API 키는 이 기기의 브라우저에만 저장되고 HTML 파일에는 들어가지 않습니다. 파일을 웹에 올려 두고 주소로 접속해도 안전하며, 기기마다 위 세 칸을 한 번씩 입력하면 됩니다.
