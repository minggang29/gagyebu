# 가계부

개인용 가계부 웹페이지입니다. HTML 파일 하나로 돌아가며, 설치할 것도 빌드할 것도 없습니다.

**주소:** https://minggang29.github.io/gagyebu/

## 쓰는 법

- PC는 위 주소를 즐겨찾기에 두고, 휴대폰은 홈 화면에 추가해 두면 됩니다.
- 기록은 브라우저에 저장되고, 클라우드 설정에 Supabase 정보를 넣으면 기기끼리 동기화됩니다.
- 휴대폰에서 MacroDroid로 카드 승인 알림을 보내면 대기 목록에 쌓입니다.

## 기능

- 대분류(수입 · 고정지출 · 변동지출 · 저축) 아래 중분류 · 소분류
- 카테고리별 예산 — 매달 같게, 또는 달마다 다르게
- 예산 대비 실적, 결제 수단별 지출, 전월 대비 증감
- 고정 지출 · 저축 일정과 카드 결제 예정액
- 지출 달력, 날짜별 메모
- 연간 보고서와 CSV 내보내기
- 가계부 여러 개 (개인 · 공용)
- 카드 문자와 앱 알림을 읽어 대기 목록으로 정리

## 파일

`index.html` 하나가 전부입니다. 외부 라이브러리를 쓰지 않습니다.
